# Поля строки `metrics:` этапа

Читается из `/stage-check`, Шаг 4.1. Строку собирает `scripts/retro.mjs` для ретро по реальным числам.

`stage` — номер этапа; `findings` — сколько находок чекеры вернули всего; `dropped` — сколько отброшено как ложные на Шаге 2; `iterations` — раундов fix-loop (0, если чинить было нечего); `fresh` — понадобился ли свежий прогон чекера (Шаг 3.3); `floor` — нарушений `floor-guard` на первом прогоне (в force — из сводки `stage-implement`, его первый прогон); `diff` — `+добавлено/-удалено` из первой строки `floor-guard` (корзины размера в ретро — по добавленным). Значения — числа и имена чекеров, без пояснений.
